Status

Where it stands

  • The full pipeline is built and working: curation, QC gate, structural checks, semantic critic, exports, and the website.
  • One gap defines the rest: the production corpus is still 100 percent legacy. Nothing has run at scale yet.
The gap

The frontier

  • Everything is proven, but only at small scale.
  • The next phase is a single goal: run the proven machinery over the real corpus.
  • Approach: forwardfill, re-curate every path fresh for uniform quality.
Go-ahead

Decisions I need from you

  • Budget sign-off for the first real batch. The full corpus is about 20 thousand dollars.
  • Confirm the evidence-sourcing policy and the full-text license scope.
Plan, over the extension

The plan, in order

  1. Unblock scale: parallel curation in git worktrees, plus a work queue to prioritize what to curate first.
  2. Run a real batch, then check its quality with a human review of the biology.
  3. Publish: wire the website to live data and export to a knowledge-graph format.
  4. Turn on the CI that is built but dormant: PR review, auto-merge, health sweep.
The vision

Future work

  • Serve the corpus as a BioThings API, registered on SmartAPI.
  • A versioned release with a Zenodo DOI.
  • Cross-validate against MechRepoNet.
From here

Next steps

  • Review the pilot results together and get your feedback on the quality bar.
  • Once the proof meets your bar, run the first real batch.
  • Report the batch quality back before scaling to the full corpus.
